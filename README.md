## ローカルでの起動方法

Node.jsをインストールした環境で、次のコマンドを実行します。

```bash
npm install
npm run dev
```

起動後、ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。

## ビルド

```bash
npm run build
npm run start
```
