# THI HA Portfolio

## အသုံးပြုနည်း

1. Zip file ကို ဖြည်ပါ။
2. `app/page.tsx`, `app/globals.css`, `app/layout.tsx` ကို မိမိ Next.js project ထဲက `app` folder သို့ copy/replace လုပ်ပါ။
3. Terminal မှာ `npm run dev` ရိုက်ပါ။
4. Browser မှာ `http://localhost:3000` ကိုဖွင့်ပါ။

## ပြင်ရန်

`app/page.tsx` ထဲက အောက်ပါအချက်တွေကို ကိုယ့်အချက်အလက်နဲ့ ပြင်ပါ။

- `your-email@example.com`
- About Me စာသား
- Project GitHub links
- Skills
